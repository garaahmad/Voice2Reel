# الشخصية والصوت والإخراج: النسخة الثانية

المستخدم رفض النسخة السابقة: شكل الشخصية، العربية الركيكة، النطق، وغياب الموسيقى والمؤثرات. هذه التغييرات تعالج التنفيذ، ولا تعني أن المستخدم اعتمد التصميم الجديد.

## تجربة مباشرة

```bash
python -m pip install -r requirements/presenter.txt
python -m voice2reel.presenter --script examples/presenter_v2/semicolon_ar.json --output outputs/new-presenter
```

التعليق هنا **فصحى بسيطة ونص مراجع مكتوب يدويًا**. لا يُعرض كأنه كتابة خام من الموديل. يشرح خطأ محددًا في جافاسكربت، ولا يدّعي أن كل الفواصل المنقوطة خاطئة.

الصوت الافتراضي أصبح `edge`، بصوت `ar-JO-TaimNeural` للعربية و`en-US-GuyNeural` للإنجليزية. هو صوت عصبي من **خدمة Microsoft Edge عبر الإنترنت** باستخدام `edge-tts==7.3.1`، وليس نموذجًا مدربًا أو مشغلًا محليًا داخل المشروع. يُرسل النص إلى الخدمة. لا يحتاج المستخدم إلى GPU أو تسجيل صوت في هذا المسار. الخدمة غير مضمونة التوفر، وعميل Edge غير الرسمي ليس بديلًا لاتفاقية خدمة إنتاجية. لا يستبدل البرنامج الصوت تلقائيًا إذا فشلت الخدمة.

للتشغيل المحلي بالكامل:

```bash
python -m voice2reel.presenter --script examples/presenter_v2/semicolon_ar.json --voice-engine piper --output outputs/offline
```

يبقى Piper متاحًا؛ لا ندّعي أن تغيير محرك الرسم حسّن نطقه. استنساخ XTTS يبقى خيارًا منفصلًا أبطأ.

## ما تغيّر بصريًا؟

- رسم أصلي جديد لوجه وقبعة وكفوف وأقدام، وخطوط أطراف متسقة ونسب جسم أقصر.
- كتفان منفصلان، منحنيات للذراع، انتقال بين الإيماءات وحركة وزن مع أقدام ثابتة على الأرض.
- أربع حالات للفم، وإغلاقه عند الصمت حتى في تعبير التعجب. حركة الفم تعتمد طاقة الصوت، وليست مزامنة فونيمات.
- طبقات الشخصية مرسومة بمقياس مضاعف، ثم مصغرة، مع كاش للوجه والكفين والنصوص.
- خط Cairo مضمن بترخيصه، يدعم العربية واللاتينية وعلامات الترقيم. لا تعتمد مقروئية النص على وجود خط بعينه في Colab.
- عبارات ترجمة أقصر داخل بطاقة واضحة. صوت Edge يوفر حدود كلمات تُستخدم لتوقيت العبارات؛ Piper/XTTS يستخدمان التوقيت التقديري السابق.
- ظهور لوحة الشرح، ومسحة لونية قصيرة عند القطع، وإبراز بصري اختياري للرمز الذي يشرحه النص.

حقول إضافية اختيارية للوحة:

```json
{"kind":"code", "code":"if (ready);", "focus":";", "status":"warning", "items":["فاصلة منقوطة بعد الشرط"]}
```

`status` يقبل `neutral` أو `warning` أو `success`. هذه بيانات من السكربت؛ المحرك لا يستنتج صحة أي كود من تلقاء نفسه ولا ينفذه. الإيماءات ما زالت مفردات محددة، وليست توليدًا حرًا لحركات جديدة.

## الموسيقى والمزج

الموسيقى الافتراضية مقطوعة آلية بسيطة مؤلفة ومولدة داخل الكود: نغمات قصيرة، خط باس وإيقاع خافت. ليست مقطعًا مسحوبًا من الريل أو من أغنية. المؤثرات تشمل انتقالًا هوائيًا ونقرات ظهور، مع نغمتين عند المشهد الأخير. تتبع التوقيت الفعلي للمشاهد.

يُطبّع الكلام إلى هدف -17 LUFS، وتُخفض الموسيقى أثناء الكلام، ويُقيد الذروة النهائية. يبقى الصوت الخام منفصلًا لتحريك الفم؛ الموسيقى لا تجعل الشخصية تتحدث أثناء الصمت.

- `narration.wav`: التعليق الخام.
- `music.wav`: الموسيقى بعد خفضها أثناء الكلام.
- `effects.wav`: المؤثرات.
- `soundtrack.wav`: المزج الذي يدخل إلى الفيديو.
- `soundtrack.json`: إعدادات المزج ومستويات القياس.

```bash
# تعطيل أي طبقة على حدة
python -m voice2reel.presenter --script script.json --no-music --output outputs/demo
python -m voice2reel.presenter --script script.json --no-sfx --output outputs/demo
# ملف موسيقى تملك حق استخدامه
python -m voice2reel.presenter --script script.json --music music.mp3 --output outputs/demo
# ضبط سرعة الصوت أو اختيار صوت متاح من اللغة نفسها
python -m voice2reel.presenter --script script.json --speech-rate 5 --neural-voice ar-JO-TaimNeural --output outputs/demo
```

تغيير الموسيقى يعيد المزج والفيديو، ويحافظ على التعليق. تغيير الصوت أو سرعته يعيد التعليق وما بعده. توجد حدود اتصال/انتظار، ومحاولتا توليد نص كحد أقصى افتراضيًا؛ المحاولة الثانية عند فشل الفحص فقط. استعمل `--text-attempts 1` لإلغاء إعادة المحاولة.

## الكتابة التلقائية وحدودها

أُضيفت تعليمات عربية وأمثلة منفصلة عن موضوع العرض: مشكلة محددة، تفسير، خطوة عملية، ومنع المقدمات والوعود والعبارات العامة. يُرفض وجود كلمات لاتينية في الكلام العربي، وتستخدم محاولة التصحيح الرد الفاشل نفسه.

هذه فحوص بنية ولغة، وليست حكمًا على جمال النص أو صحة كل معلومة. تجربة الموديل المحلية أظهرت صياغات ركيكة حتى بعد تعديل التعليمات؛ تُحفظ محاولة مرفوضة في `examples/presenter_v2/failed_ai_attempts`. لا نعرض نجاح توليد الصوت والرسم كدليل على جودة الكتابة. راجع السكربت قبل النشر، أو استخدم نصًا مراجعًا.

تحسين الصورة والصوت لا يحل محدودية Qwen3 4B تلقائيًا. يمكن أن يستغرق التصحيح النصي وقتًا إضافيًا على CPU. أزمنة النسخة القديمة تخص تلك النسخة ولا تمثل الرسم والصوت الجديدين. التنفيذ على GPU أو تخصيص Colab فعلي غير مقاس هنا.

المصادر: [edge-tts](https://github.com/rany2/edge-tts)، [توثيق أصوات Microsoft](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts)، [Cairo ومصدر ترخيصه](https://github.com/google/fonts/tree/main/ofl/cairo). حقوق الخدمة الصوتية منفصلة عن ترخيص العميل. التراخيص الصوتية القديمة لـPiper وXTTS لم تتغير.
