# الاتجاه الحالي: ستيكمان بإخراج وأنيميشن

المطلوب فيديو ستيكمان مرتب وجميل: الشخصية تؤدي فعلًا وتُظهر ردّة فعل، مع مشاهد مترابطة وعناصر تتفاعل معها. المشاهد الواقعية لم تعد هدف المشروع.

## ملامح النتيجة المطلوبة

- تصميم 2D واضح ومتّسق، بخطوط ناعمة وألوان محدودة وخلفيات تخدم القصة.
- حركة متصلة: مشي، تغيّر في مركز الثقل، وصول إلى الأشياء، تلامس، ردّة فعل واستقرار بعد الحركة.
- استعداد قبل الفعل، وتسارع وتباطؤ، وحركة تتبع الفعل بدل توقف جميع الأجزاء في اللحظة نفسها.
- تعبيرات وجه ونظرات ورمش مرتبطة بما يحدث.
- تنويع مقصود في تكوين اللقطة وحركة الكاميرا، مع ثبات تصميم الشخصية.
- كتابة وعناصر موشن جرافيك تظهر وقت الحاجة، مع تعليق صوتي عربي أو إنجليزي.

الفكرة والأسئلة الخمسة والتخطيط والسكربت والصوت ما زالت ضمن المسار. الفيديو المرجعي اختياري. العينة الصوتية اختيار مستقل للاستنساخ.

## ما أُنجز الآن؟

`voice2reel.motion_preview` معاينة صامتة مدتها تسع ثوانٍ، مكتوبة يدويًا لاختبار محرك الرسم. تعرض المشي، ثم الوصول إلى زر، واستجابته، وردّة فعل وقفزة واستقرارًا. أطراف الشخصية مفصلية، واليدان تتحركان نحو أهداف باستخدام حساب المفاصل، مع رمش ونظرات وكاميرا متحركة.

هذه المعاينة ليست فيلمًا مولدًا بالـAI، وليست دمجًا نهائيًا مع الصوت أو السكربت. لا تحلل فيديو مرجعيًا، ولا تتضمن مزامنة شفاه. هدفها جعل اتجاه الشكل والحركة قابلًا للمشاهدة.

```bash
python -m pip install -r requirements/render.txt
python -m voice2reel.motion_preview --output outputs/stickman-motion-study.mp4
```

يلزم ffmpeg وخط يدعم العربية. الرسم يعمل على CPU. توليد النص والصوت وتدريب النماذج متطلبات منفصلة.

## ما الذي يتبقى للمحرك الكامل؟

1. صيغة مشاهد للستيكمان تحدد الشخصيات والعناصر والأفعال والتعابير والكاميرا، مع إطارات مفتاحية وتوقيتات.
2. تحويل خطة AI إلى هذه الصيغة والتحقق من الأفعال والاتصالات الممكنة.
3. توسيع مكتبة الأفعال والمواقع والتفاعلات، وإضافة مزج الحركات والانتقال بين المشاهد.
4. ضبط الحركة على مدة الكلام الفعلية وإضافة العناوين والعناصر التوضيحية.
5. اختبار الفيديو الكامل ومراجعته بصريًا؛ جودة النص ما زالت تحتاج مراجعة مستقلة.

لن يكفي تغيير كلمة realistic إلى stickman في البرومبت: محرك الستيكمان الحالي القديم محدود، وخطة تجربة LTX ليست خطة حركة مفصلية. المعاينة الجديدة بداية منفصلة لتطوير هذا الجزء، بينما يبقى الرندر القديم قابلًا للتشغيل كتجربة أساسية.
