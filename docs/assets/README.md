# README visual assets

- `hero.png`: project banner with actual frames from the current presenter renderer.
- `presenter-demo.gif`: nine-second, 10 FPS silent visual preview at 360 × 640.
- `scene-gallery.png`: three actual renderer frames showing the example's gestures and code panels.

Frames use `examples/presenter_v2/semicolon_ar.json` and `PresenterRenderer`. Each scene is assigned three seconds for this visual demonstration. Synthetic audio energy drives mouth movement; no online speech, real narration, or provider word timings were generated. The GIF is a renderer preview, not evidence of a complete speech-generation run or render-speed benchmark.

The banner and gallery use DejaVu Sans. Arabic frames use the project's bundled Cairo font; see `voice2reel/assets/Cairo-OFL.txt`.
