# Bundled Cairo font

Original Cairo variable font by Mohamed Gaber and contributors, distributed under SIL Open Font License 1.1. The unmodified upstream font is bundled with its complete license in `Cairo-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/cairo
Downloaded 2026-11-09. SHA-256: `667c987182391c91f4e57a2f455b1794fb5e3ee6ca4ef3383e86bb690fa9c964`.

This font contains Arabic, Latin and punctuation in one font. Bundling prevents missing Latin letters or ellipsis when mixing Arabic captions with programming terms. Font variations use weight 700 and upright slant at rendering time; the source font file is unmodified.
