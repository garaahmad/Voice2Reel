# Actual one-pass AI run

The project actually ran Qwen3-4B-Instruct-2507 (Unsloth Q4_K_M, pinned revision), Piper Arabic and the 2D renderer on a CPU-only host with a two-core quota. Files preserve the raw model response, compiled script, request, audio timings and measured stage durations. The script was not rewritten by the assistant. This is a functional generation sample, not an Arabic writing or pronunciation benchmark. The model's wording still needs editorial review before publishing.

This observed run used local model files and no prior output cache. Model downloads are excluded. Later renderer/controller refinements can change timings and camera defaults; the report is one measurement, not a guaranteed service time.
