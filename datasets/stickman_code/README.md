# Stickman Python Code Dataset

This folder defines a **future** Qwen Coder supervised fine-tuning corpus. No runnable training examples have been produced or verified yet.

See [implementation plan](../../docs/QWEN_STICKMAN_CODE_TRAINING.md) and [JSON Schema](schema.json).

Do not mix this corpus with existing drawing-plan or narration datasets. First implement and pin the animation engine API; then generate render-verified examples and grouped train/validation/test splits. The proposed 10,000 rows are a target, not an existing dataset.
